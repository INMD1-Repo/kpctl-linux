# 개발 안내

[문서 목차](../README.md)

변경할 정책을 [기능 명세](../features/README.md)에서 찾고, [코드 위치 지도](code-map.md)의 실제 선언으로 이동합니다. 설정은 각 프로그램의 `ParseConfig`가 JSON 해석·기본값·검증을 담당하고 `LoadConfig`가 파일 읽기와 작업 디렉터리 생성을 더합니다. 문서 검사도 같은 parser를 사용합니다.

상태/API 구조는 [model](../../internal/model/model.go)의 필드를 추가하는 방식으로 확장합니다. 기존 이름과 해시 검증, 정확한 Ubuntu 기준 입력, 누적 교체와 링 순서를 보존해야 합니다. 미확인 환경 오류를 패치 자체의 불가 판정으로 바꾸지 않습니다.

[시험](testing.md)은 가짜 도구·실제 셸 계약과 실제 커널 검증을 구분합니다. [웹 개발](web.md)은 개발 전용 API와 운영 내장 번들의 경계를 설명합니다. 문서·설정·CLI를 바꾸면 `make docs-check`를 실행하고 선언 위치 변경 뒤에는 코드 지도를 재생성합니다.
